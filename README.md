# 📝 Convertidor Word ↔ PDF

Aplicación de escritorio desarrollada por **Victor Aza** en **Python** con **Tkinter**, que permite convertir archivos de **Word (.docx)** a **PDF** y también de **PDF** a **Word (.docx)**.  
Ofrece una interfaz sencilla y visualmente clara para facilitar las conversiones sin necesidad de usar herramientas en línea.

---

## 🚀 Características principales

- Conversión rápida y sencilla entre formatos **Word** y **PDF**.  
- Interfaz gráfica intuitiva con botones para cada tipo de conversión.  
- No requiere conexión a Internet.  
- Compatible con Windows, Linux y macOS.

## 🛠️ Tecnologías utilizadas

- **Python 3**
- **Tkinter** → para la interfaz gráfica.
- **docx2pdf / pypandoc / reportlab** → para realizar las conversiones de archivos.

---

## ⚙️ Instalación

1. Asegúrate de tener **Python 3.10 o superior** instalado.  
2. Clona o descarga el repositorio:  
   ```bash
   git clone https://github.com/1993victoram/Convertidor-de-formato-de-archivos.git
   ```
3. Instala las librerías necesarias:  
   ```bash
   pip install docx2pdf pypandoc reportlab
   ```
4. Ejecuta el programa:  
   ```bash
   python convertir.py
   ```

---

## 🖥️ Uso

1. Abre la aplicación (`convertir.py`).  
2. Selecciona el tipo de archivo que deseas convertir:  
   - **Word (.docx) → PDF**  
   - **PDF → Word (.docx)**  
3. Elige el archivo desde el explorador y guarda la conversión en la carpeta deseada.
